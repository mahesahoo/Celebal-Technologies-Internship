# Celebal Technologies Internship — Data Science / ML Track

Weekly assignment submissions for a structured data science / machine learning internship,
progressing from Python fundamentals through supervised learning, unsupervised learning, deep
learning (CNNs, autoencoders, RNNs), and Retrieval-Augmented Generation.

Each week is a single, fully-executed Jupyter notebook named `week[N]_maheswar_sahoo.ipynb`, with
outputs baked in (no re-execution required to view results).
